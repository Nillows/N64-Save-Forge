What this is. A save editor and analyzer for The Legend of Zelda: Ocarina of Time (N64, NTSC). Load a save and every flag below is filled in with its current state — that's the analyzer. Toggle anything and download a valid file — that's the editor. It auto-detects byte order (.sra / .srm / byte-swapped) by scanning for the ZELDAZ marker, edits in place so container files survive, and recomputes the slot checksum on every change so the game accepts the result. Back up your original save first. Each game is one schema, so this same engine extends to other titles without code changes.
